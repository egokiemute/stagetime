## Edit your programs
- **Edit** a loaded program: add, remove, rename, retime and reorder segments. Segments that have already started can still be renamed or retimed, and changing the running one moves its countdown instead of restarting it.
- **Save** now updates the loaded program in place. Programs with unsaved changes are marked "• unsaved".
- **Manage saved programs**: load, rename, delete, or save a copy under a new name.

## Control it from your phone
- Turn on **Phone control** in the sidebar and scan the QR code with any phone on the same Wi‑Fi.
- Enter the 4-digit PIN shown on the laptop, then start, pause and nudge the timer, step through or edit the program, and send stage messages.
- Phone control is off every time the app starts, and the PIN changes each time you turn it on.

## A new look
- Redesigned control window in the style of a native macOS app: a sidebar for the run of service, a larger clock that changes colour as time runs low, and clearer controls with keyboard shortcuts shown.

## Fixes
- The **Save** button now asks for a name properly. Before, it could fail silently.
- Pasting a new program no longer risks overwriting the previously loaded saved program.
